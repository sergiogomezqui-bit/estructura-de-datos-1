# Estructura de Datos 1 — Introducción a FrontEnd Dinámico (DOM)

Página web con un formulario (nombre, edad, peso, ciudad) que se completa y muestra en pantalla usando manipulación del DOM — práctica en grupo de la sesión de Introducción a FrontEnd Dinámico del curso.

## Contenido

- `index.html` — formulario de entrada y área de respuesta
- `Scripts/funciones.js` — arma el texto con los datos de la persona
- `Scripts/main.js` — conecta los botones del formulario con el DOM: ingresar una persona y recordar (ver) todas las ingresadas
- `Styles/main.css` — estilos de la página

## Uso

Abre `index.html` con Live Server (o cualquier servidor estático), completa el formulario y presiona **Ejecutar**. El botón **Recordar** muestra el historial de todo lo ingresado en la sesión.
